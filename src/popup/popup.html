🔧 Troubleshooting Guide

❌ Getting 503 errors?

API hashes may be expired. Follow these steps:

  1. Click "Clear Hash Cache" button above
  2. Visit x.com
  3. Perform the core actions below:
1
bookmarkTweetToFolder Core

Bookmark any tweet → "Add to folder" → select a folder

2
createBookmarkFolder Core

Bookmark → "Add to folder" → "Create new folder"

3
BookmarkFoldersSlice Core

Visit Bookmarks page

Optional (for extra features)
4
CreateBookmark Optional

Bookmark any tweet (click 🔖 icon)

5
DeleteBookmark Optional

Unbookmark the tweet (click 🔖 again)

6
BookmarkFolderTimeline Optional

Click any bookmark folder to view contents (for export feature)

7
RemoveTweetFromBookmarkFolder Optional

⚠️ May not be available in Twitter's current UI. Skip if you can't find it.

✅ After completing all actions:

1. Close this panel
2. All items should show green dots
3. Try using the extension again
